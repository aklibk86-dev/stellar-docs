# 配置文件生成器

通过可视化界面生成 Stellar 主题的运行时配置文件（`env.js`），修改后无需重新构建，刷新页面即可生效。

## 使用说明

1. **基本信息**：填写路由基础路径、站点标题、站点简介等
2. **外观**：配置主题模式、背景图片、Logo 等
3. **客户端下载**：设置各平台客户端下载链接
4. **API 连接**：配置 API 地址、后端类型等
5. **生成文件**：复制生成的代码，替换 `public/env.js`
